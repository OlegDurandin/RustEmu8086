## Недочёты

- Редактор каждый кадр заново подсвечивает весь текст (и копирует его, если есть точки останова или
  закладки) — на больших файлах заметно; кешировать по строкам. `editor.rs`
- Вложенные `IF` — квадратичное время (100 000 уровней — 4,8 с).
- Запасные шрифты для CP437 — только пути macOS (`fonts.rs`); на других системах их нет.
- В вебе эмодзи в тексте пользователя — квадратики (в шрифтах только значки интерфейса).
- В вебе: ☻ ☼ ⌂ ⁿ в окнах с текстом, нет PWA/офлайна, кеш GitHub Pages — 10 минут.
- Очень большие файлы: `app.rs`, `reference.rs` — разделить.
- Незакрытые пункты плана: 2.8 (`STRUC`, `IRP/IRPC`, `ASSUME`), 3.7 (CGA 4/5/6, VGA 12h), 6.6 (FASM).
- INT 33h — базово; нет INT 21h/4Bh (запуск программ).
- NASM: нет EXE, `%define` с параметрами, `%rotate`, `incbin`, `struc`, контекстных макросов.

## Фичи для развития

- **Обучение:** задания с автопроверкой (вход → ожидаемый вывод/регистры), уроки по шагам.
- **Наглядность:** счётчик тактов 8086 и тепловая карта исполнения по строкам, диаграмма стека.
- **Отладчик:** точки останова на запись/чтение памяти, обратное выполнение до точки (reverse continue).
- **Редактор:** автодополнение, переход к определению метки/переменной, структура файла (outline).
- **Платформы:** PWA с офлайном; сборки для Linux и Windows.
- **Разное:** звук PC speaker (порт 61h + PIT), русский интерфейс, ссылки «поделиться» с точками
  останова и watch.
