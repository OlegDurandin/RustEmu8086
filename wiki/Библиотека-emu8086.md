# Библиотека emu8086.inc

`emu8086.inc` — набор макросов и процедур для ввода и вывода, как в Emu8086. Он встроен в программу,
отдельный файл не нужен:

```asm
include 'emu8086.inc'
```

Все макросы и процедуры печатают через BIOS INT 10h, функция 0Eh. Это собственная реализация с тем же
видимым поведением, что у Emu8086, а не исходный файл Emu8086.

## Макросы

Разворачиваются прямо там, где написаны.

| Макрос | Что делает | Сохраняет |
|---|---|---|
| `PUTC char` | печатает один символ; `char` — константа (`'A'`, `13`) или 8-битный регистр | AX |
| `GOTOXY col, row` | ставит курсор: `col` 0..79, `row` 0..24 (константы или 8-битные регистры) | AX, BX, DX |
| `PRINT 'text'` | печатает строку без перевода строки | AX, SI |
| `PRINTN 'text'` | печатает строку и перевод строки (CR, LF) | AX, SI |
| `CURSOROFF` | прячет текстовый курсор | AX, CX |
| `CURSORON` | показывает курсор снова | AX, CX |

## Процедуры

Код процедуры вставляет макрос `DEFINE_…` — один раз, обычно после последнего `RET` программы. Вызов —
`CALL`.

| Вставить | Вызвать | Что делает |
|---|---|---|
| `DEFINE_SCAN_NUM` | `CALL SCAN_NUM` | читает число со знаком (−32768..32767) с клавиатуры в **CX**. Каждая клавиша отображается; лишние символы стираются, Backspace удаляет цифру, `-` — минус, Enter завершает |
| `DEFINE_PRINT_NUM` | `CALL PRINT_NUM` | печатает число со знаком из **AX**. Нужен ещё `DEFINE_PRINT_NUM_UNS` |
| `DEFINE_PRINT_NUM_UNS` | `CALL PRINT_NUM_UNS` | печатает число без знака из **AX** (0..65535) |
| `DEFINE_PRINT_STRING` | `CALL PRINT_STRING` | печатает строку с нулём в конце по адресу **DS:SI** |
| `DEFINE_PTHIS` | `CALL PTHIS` + `DB 'текст', 0` | печатает строку, записанную сразу после `CALL`, и продолжает после неё |
| `DEFINE_GET_STRING` | `CALL GET_STRING` | читает строку в буфер **DS:DI**; **DX** — размер буфера с завершающим нулём |
| `DEFINE_CLEAR_SCREEN` | `CALL CLEAR_SCREEN` | очищает экран и ставит курсор в левый верхний угол |

## Пример

```asm
include 'emu8086.inc'
org 100h
    print 'Enter a number: '
    call scan_num           ; CX = number
    mov ax, cx
    add ax, ax
    printn ''
    print 'Twice: '
    call print_num
    ret
DEFINE_SCAN_NUM
DEFINE_PRINT_NUM
DEFINE_PRINT_NUM_UNS
```

## Как посмотреть, что внутри

- Наведите мышь на имя макроса в редакторе — появится описание; **⌘-клик** открывает код.
- **Help → emu8086.inc library** (или ⌘-клик по строке `include 'emu8086.inc'`) — все макросы и процедуры с
  описанием и кодом.
- При отладке **F8** на строке с макросом заходит внутрь: окно исходника показывает код библиотеки и текущую
  строку (галочка **step into macros**), **⇧F11** возвращает к вызову, **F10** выполняет макрос целиком.
