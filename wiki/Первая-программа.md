# Первая программа

За 10 минут: напишем программу, запустим её, пройдём по шагам и прочитаем число с клавиатуры. Всё ниже
работает одинаково в [веб-версии](https://olegdurandin.github.io/RustEmu8086/) и в приложении для Mac
(клавиши в браузере те же).

## 1. Hello, World

Нажмите **new** на панели. В окне *choose code template* выберите **COM template** и нажмите **OK** — откроется заготовка.
Замените её текст на:

```asm
org 100h
    mov ah, 9               ; DOS: print a string ending with '$'
    mov dx, offset msg
    int 21h
    ret                     ; back to DOS
msg db 'Hello, 8086!', 13, 10, '$'
```

Нажмите **▶ emulate** (или **F9**). Программа соберётся и загрузится в эмулятор: как в Emu8086, откроются окна
**emulator** (регистры и дизассемблер), **emulator screen** и **original source code**. Если в **options** выбраны
панели (**windows: panels**), то же откроется вкладками рядом с редактором, без перекрытий.

Нажмите **Run** (**F5**) — на экране эмулятора появится `Hello, 8086!`, а внизу главного окна —
`Program terminated (exit code 0)`.

Что здесь происходит:

- `org 100h` — программа в формате COM: DOS загружает её со смещения 100h.
- `mov ah, 9` + `int 21h` — функция 09h DOS печатает строку по адресу DS:DX до символа `$`.
- `13, 10` — перевод строки (CR, LF).
- `ret` в COM-программе возвращает управление DOS.

## 2. Ошибка сборки

Замените `mov ah, 9` на `mov ah, 300` и нажмите **F9**. Внизу появится сообщение вида
`(2:13): value 300 out of byte range`, а в редакторе число будет подчёркнуто волнистой линией. Клик по
сообщению выделяет место ошибки. Верните `9`.

## 3. По шагам

Возьмём программу, которая считает сумму 1 + 2 + 3 + 4 + 5:

```asm
org 100h
    mov cx, 5               ; counter
    xor ax, ax              ; sum = 0
    mov bx, 1
next:
    add ax, bx              ; sum += bx
    inc bx
    loop next               ; cx--, repeat while cx != 0
    ret                     ; AX = 1+2+3+4+5 = 15
```

Нажмите **F9**, затем несколько раз **F8** (**Single step**):

- текущая строка подсвечена в редакторе стрелкой ▶ и в окне исходника;
- изменившиеся регистры в окне эмулятора выделены красным;
- `loop next` уменьшает CX и прыгает назад, пока CX не станет 0.

Проскочили нужное место — нажмите **⇧F8** (**Step back**): эмулятор вернётся на шаг назад, со всеми регистрами
и памятью. Назад можно пройти до 2000 шагов.

Наведите мышь на `ax` в редакторе — подсказка покажет текущее значение. В конце AX = 000Fh = 15.

## 4. Точка останова

Кликните по полю слева от номера строки `inc bx` — появится красная точка. Нажмите **F5**: программа
остановится на этой строке. Правый клик по строке → **Breakpoint condition…** откроет окно **breakpoints**;
впишите условие, например `bx == 4`, — теперь остановка будет только на четвёртом проходе. Подробнее — [Отладка](Отладка).

## 5. Ввод с клавиатуры

Библиотека `emu8086.inc` даёт готовые макросы для ввода и вывода чисел:

```asm
include 'emu8086.inc'
org 100h
    print 'Enter a number: '
    call scan_num           ; the number -> CX
    mov ax, cx
    add ax, ax
    printn ''
    print 'Twice: '
    call print_num          ; prints AX
    ret
DEFINE_SCAN_NUM
DEFINE_PRINT_NUM
DEFINE_PRINT_NUM_UNS
```

Нажмите **F9** и **F5**. Когда программа ждёт ввода, щёлкните по окну **emulator screen** и наберите число,
например `21`, затем Enter — программа выведет `Twice: 42`. На планшете откроется экранная клавиатура.

`DEFINE_SCAN_NUM` и другие `DEFINE_…` вставляют код процедур — их пишут один раз, после `ret`. Все макросы
описаны на странице [Библиотека emu8086.inc](Библиотека-emu8086).
