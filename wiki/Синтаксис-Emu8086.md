# Синтаксис Emu8086 (MASM)

Основной язык RustEmu8086 — диалект MASM, который понимает Emu8086. Программы из учебников и примеры
Emu8086 собираются без изменений. Второй язык — [NASM](Синтаксис-NASM); синтаксис определяется сам.

Полное описание каждой инструкции (флаги, пример) — во встроенном справочнике: **F1** на слове в редакторе.

## Строка программы

```asm
метка:  инструкция  операнды    ; комментарий
```

Регистр букв не важен: `MOV AX, BX` и `mov ax, bx` — одно и то же.

## Формат программы

| Формат | Как выбрать | Где загружается |
|---|---|---|
| **COM** | `org 100h` (или `#make_com#`) | `0700:0100`, CS = DS = ES = SS |
| **EXE** | сегменты `segment … ends` или `.model/.code` (или `#make_exe#`) | модуль с сегмента `0710h`, DS = ES = PSP |
| **BIN** | `#make_bin#` | `#load_segment=#` (по умолчанию `0100h`) |
| **BOOT** | `#make_boot#` | `0000:7C00`, не больше 512 байт |

Без директивы `#make_…#`: `org 100h` — COM (даже если есть `.data` / `.code`), иначе при наличии сегментов —
EXE, иначе COM. **new** на панели предлагает шаблоны всех четырёх форматов.

Сегмент (и вся COM-программа) не может быть больше 64 КБ — ассемблер покажет строку, которая выходит за
границу.

### COM

```asm
org 100h
    mov ah, 9
    mov dx, offset msg
    int 21h
    ret
msg db 'Hello!$'
```

### EXE

```asm
#make_exe#
data segment
    msg db 'Hello from EXE!', 0Dh, 0Ah, '$'
ends
stack segment
    dw 128 dup(0)
ends
code segment
start:
    mov ax, data            ; DS is not set for you in an EXE
    mov ds, ax
    lea dx, msg
    mov ah, 9
    int 21h
    mov ax, 4C00h           ; terminate
    int 21h
ends
end start                   ; entry point
```

Упрощённая форма: `.model small`, `.stack`, `.data`, `.code`, `.startup` (ставит DS) и `.exit`.

## Данные

```asm
b   db 5, 'A', 0FFh         ; bytes
w   dw 1234h, -1            ; words
d   dd 12345678h            ; double word
s   db 'text', 13, 10, '$'  ; string
arr dw 10 dup(0)            ; 10 zero words
buf db 80 dup(?)            ; reserved, not initialized
N   equ 10                  ; constant
X = N * 2                   ; redefinable constant
```

Числа: `10`, `0Ah`, `1010b`, `17o`, символы `'A'`. В выражениях: `+ - * / mod`, `shl shr`, `<< >>`,
`and or xor not`, сравнения, `$` — текущий адрес.

## Переменная или метка

Это главная особенность Emu8086:

| Объявление | Что такое имя | `mov ax, имя` |
|---|---|---|
| `count dw 5` | **переменная** — ячейка памяти с типом | читает значение из памяти |
| `count: dw 5` | **метка** (с двоеточием) — просто адрес | загружает адрес |
| `next:` | метка в коде | загружает адрес |

Адрес переменной — `offset count` или `lea dx, count`, сегмент — `seg count`. Элемент массива — `arr[si]`,
`arr[bx+2]`, `[arr+4]`.

## Размер операнда

| Код | Что получится |
|---|---|
| `mov ax, [bx]` | слово — размер по регистру |
| `mov [bx], 5` | **байт**, если число помещается в байт (как в Emu8086), иначе слово |
| `inc [bx]` | ошибка: размер неизвестен |
| `inc byte ptr [bx]`, `inc b.[bx]` | байт |
| `inc word ptr [bx]`, `inc w.[bx]` | слово |
| `mov al, var` (`var dw`) | регистр важнее типа переменной — читается байт |

## Процедуры и макросы

```asm
print_char proc near        ; FAR: RET becomes RETF
    mov ah, 0Eh
    int 10h
    ret
print_char endp

newline macro               ; expanded where it is written
    local skip              ; a unique label in every expansion
    mov al, 13
    call print_char
    mov al, 10
    call print_char
endm
```

Параметры макросов: `name macro a, b`; значение по умолчанию — `a:=1`. Ещё: `rept n … endm`,
`if / ifdef / ifndef / else / endif`, `include 'file.inc'`.

## Директивы Emu8086

| Директива | Что делает |
|---|---|
| `#make_com#`, `#make_exe#`, `#make_bin#`, `#make_boot#` | формат программы |
| `#load_segment=0500#`, `#load_offset=0000#` | куда загрузить BIN (hex) |
| `#cs=…#`, `#ip=…#`, `#ax=…#`, `#ds=…#` … | регистры при старте BIN |
| `#mem=адрес,байты#` | записать байты в память перед запуском |
| `#start=robot.exe#` | открыть [виртуальное устройство](Виртуальные-устройства) |

## Особенности (как в Emu8086)

- Дальний условный переход (дальше −128…+127 байт) собирается парой «обратный короткий переход + `jmp near`».
  `jcxz` вне диапазона — `or cx, cx` + `jz`.
- `shl ax, 3` у 8086 нет — собирается как три `shl ax, 1`.
- Работают расширения 80186: `pusha`, `popa`, `push 5`, `imul ax, bx, 3`, `leave`.
- Всё после `end` игнорируется.

Чего нет: `STRUC`, `IRP` / `IRPC`, автоматических префиксов по `ASSUME` — см. [Отличия от Emu8086](Отличия-от-Emu8086).

## Сборка в файл

**compile** (**⌘B**) записывает рядом с исходником `.com` / `.exe` / `.bin`, листинг `.lst` и таблицу
символов `.symbol`. В браузере собранный файл скачивается.
