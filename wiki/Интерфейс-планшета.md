# Интерфейс планшета

На iPad и других планшетах RustEmu8086 работает через [веб-версию](Веб-версия): в браузере она сама выбирает
интерфейс для касаний. Отдельного приложения для iPadOS и Android нет — браузер даёт то же самое без установки.
Сайт можно добавить на экран «Домой»: Safari → «Поделиться» → «На экран Домой».

Тёмная тема, крупные элементы под палец.

## Верхняя панель

Имя файла и кнопки **Run / Pause / Step / Reset**. Run, Step и Reset сами собирают программу, если текст
изменился.

## Вкладки

- **Editor** — редактор, регистры (AX–DX по байтам: AH | AL), флаги (касание переключает флаг), дизассемблер,
  память, вывод: экран эмулятора или сообщения ассемблера.
- **Debugger** — дизассемблер с точками останова (касание поля слева), регистры, экран эмулятора, стек вызовов,
  точки останова с переключателями, watch, трасса последних шагов.
- **Memory** — hex-редактор (сегмент, переход к адресу, поиск байтов или текста, ввод в HEX или ASCII, 8/16/32
  байта в строке), инспектор байта, сегментные регистры, стек, карта 1 МБ памяти.

В альбомной ориентации карточки стоят тремя колонками, в портретной — двумя с нижним рядом, в узком окне
(Split View) — друг под другом.

## Экранная клавиатура

Для ввода в программу, которая работает в эмуляторе. Открывается значком клавиатуры рядом с ⋮, касанием
экрана эмулятора и сама, когда программа ждёт ввода (INT 21h / INT 16h).

- Раскладка US и клавиши для DOS-программ: Esc, Tab, Ctrl, стрелки, по клавише **Fn** — F1–F10,
  Ins / Del / Home / End / PgUp / PgDn.
- Shift и Ctrl действуют на одну следующую клавишу.
- Рядом — экран эмулятора крупно (строки вокруг курсора).

Код в редакторе набирается обычной клавиатурой планшета.

## Меню ⋮

- файлы: New, Open, Examples, Save, Save as, Download, **Share link…**;
- отладка: Assemble and load, Step back, Step over, Step out, Run to cursor;
- окна: Virtual devices, **Drive C: files**, Variables, Symbol table, Listing, ALU, Stop on condition,
  Debug console;
- инструменты: Reference, Calculator, Base converter, ASCII codes;
- *Desktop layout* — переключение на интерфейс Emu8086, Options, About.
