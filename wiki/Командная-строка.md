# Командная строка

`rustemu` собирает, запускает и дизассемблирует программы без окон — удобно для проверки заданий и скриптов.

Где взять:

- в приложении для Mac: `/Applications/RustEmu8086.app/Contents/MacOS/rustemu`;
- из исходников: `cargo build --release -p rustemu-cli` → `target/release/rustemu`.

## Сборка — `rustemu asm`

```sh
rustemu asm hello.asm                 # -> hello.com
rustemu asm hello_exe.asm -l -s       # .exe + listing (.lst) + symbols (.symbol)
rustemu asm prog.asm -o out.bin       # output file name
rustemu asm boot.asm --syntax nasm    # nasm or masm; detected by default
```

## Запуск — `rustemu run`

Запускает `.asm` (сначала собирает), `.com`, `.exe`, `.bin` или `.boot`. Вывод программы печатается в
терминал.

```sh
rustemu run hello.asm
rustemu run calc.asm --input '12\n30\n'      # keyboard input, \n = Enter
echo 21 | rustemu run twice.asm              # without --input: stdin
rustemu run prog.asm --args "p1 p2"          # DOS command line (PSP:80h)
rustemu run colors.asm --screen              # print the final text screen
rustemu run sum.asm --trace                  # every instruction with registers
```

| Опция | Что делает |
|---|---|
| `--input <text>` | ввод с клавиатуры (`\n` — Enter); без неё — stdin |
| `--args <text>` | параметры командной строки DOS (PSP:80h) |
| `--max <n>` | предел числа инструкций (по умолчанию 100 000 000) |
| `--screen` | напечатать итоговый текстовый экран вместо потока вывода |
| `--trace` | печатать каждую выполненную инструкцию |
| `--timer-irq` | включить IRQ0 (INT 08h / 1Ch) 18,2 раза в секунду |

Код возврата `rustemu run` — код завершения программы (AL в INT 21h, функция 4Ch), так что результат можно
проверять в скриптах:

```sh
rustemu run task.asm --input '5\n' > out.txt && diff out.txt expected.txt
```

Пример трассы:

```
0700:010D  RET                          AX=000F BX=0006 CX=0000 DX=0000 SP=FFFE F=F206
```

## Дизассемблер — `rustemu disasm`

```sh
rustemu disasm hello.com
rustemu disasm boot.bin --org 7C00
```

`rustemu` без аргументов печатает краткую справку.
