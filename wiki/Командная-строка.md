# Командная строка

[English](Command-line) · **Русский**

`rustemu` собирает, запускает и дизассемблирует программы — для 8086 и для [MIPS32](Процессор-MIPS32) — без окон — удобно для проверки заданий и скриптов.

Где взять:

- в приложении для Mac: `/Applications/RustEmu8086.app/Contents/MacOS/rustemu`;
- из исходников: `cargo build --release -p rustemu-cli` → `target/release/rustemu`.

## Сборка — `rustemu asm`

```sh
rustemu asm hello.asm                 # -> hello.com
rustemu asm hello_exe.asm -l -s       # .exe + listing (.lst) + symbols (.symbol)
rustemu asm prog.asm -o out.bin       # output file name
rustemu asm boot.asm --syntax nasm    # nasm or masm; detected by default
```

## Запуск — `rustemu run`

Запускает `.asm` (сначала собирает), `.com`, `.exe`, `.bin` или `.boot`. Вывод программы печатается в
терминал.

```sh
rustemu run hello.asm
rustemu run calc.asm --input '12\n30\n'      # keyboard input, \n = Enter
echo 21 | rustemu run twice.asm              # without --input: stdin
rustemu run prog.asm --args "p1 p2"          # DOS command line (PSP:80h)
rustemu run colors.asm --screen              # print the final text screen
rustemu run sum.asm --trace                  # every instruction with registers
```

| Опция | Что делает |
|---|---|
| `--input <text>` | ввод с клавиатуры (`\n` — Enter); без неё — stdin |
| `--args <text>` | параметры командной строки DOS (PSP:80h) |
| `--max <n>` | предел числа инструкций (по умолчанию 100 000 000) |
| `--regs` | напечатать регистры в конце (в stderr) |
| `--screen` | напечатать итоговый текстовый экран вместо потока вывода |
| `--trace` | печатать каждую выполненную инструкцию |
| `--timer-irq` | включить IRQ0 (INT 08h / 1Ch) 18,2 раза в секунду |
| `--keys <text>` | MIPS: клавиши клавиатуры MMIO MARS (`\n` — Enter) |
| `--delayed-branching`, `--self-modifying`, `--start-at-main`, `--no-pseudo`, `--warnings-are-errors` | MIPS (и в `asm`): настройки MARS, его ключи `db`, `smc`, `sm`, `np`, `we` |
| `--memory <config>` | MIPS (и в `asm`): конфигурация памяти MARS: `Default`, `CompactDataAtZero`, `CompactTextAtZero` (его `mc`) |
| `--project` | MIPS (и в `asm`): собрать вместе с программой файлы `.asm` и `.s` её папки (`p` MARS) |
| `--exception-handler <file>` | MIPS (и в `asm`): собрать этот файл первым (настройка обработчика исключений MARS) |
| `--program-args <text>` | MIPS: аргументы программы через пробел (`pa` MARS): `$a0` — их число, `$a1` — массив их адресов |

Код возврата `rustemu run` — код завершения программы (AL в INT 21h, функция 4Ch), так что результат можно
проверять в скриптах:

```sh
rustemu run task.asm --input '5\n' > out.txt && diff out.txt expected.txt
```

Пример трассы:

```
0700:010D  RET                          AX=000F BX=0006 CX=0000 DX=0000 SP=FFFE F=F206
```

## Дизассемблер — `rustemu disasm`

```sh
rustemu disasm hello.com
rustemu disasm boot.bin --org 7C00
```

## Программы MIPS32

Файлы `.s` и исходники, написанные для MIPS (регистры вроде `$t0`, `syscall`), собираются и выполняются как
программы MIPS32 в диалекте MARS; `--arch mips` или `--arch 8086` задаёт это явно.

```sh
rustemu asm sort.s -l -s                     # проверка; листинг (.lst, text segment MARS) + символы
rustemu asm sort.s -o sort.bin               # сегмент кода в двоичном виде (dump .text MARS)
rustemu run sum.s --input '100\n'            # ввод Run I/O; \n — Enter
rustemu run keyboard_display.s --keys 'hi\n' --max 500000   # клавиши клавиатуры MMIO
rustemu run sort.s --delayed-branching     # настройки MARS, как его db (см. Процессор MIPS32)
rustemu asm sort.s --memory CompactTextAtZero -o sort.bin   # сегмент кода с адреса 0
rustemu run fibonacci.s --regs               # напечатать регистры в конце
rustemu run hello.s --trace                  # каждая инструкция с $v0 $a0 $t0 $t1 $sp
rustemu disasm sort.bin --arch mips          # с 0x00400000; --org — другой адрес
rustemu disasm sort.bin --arch mips --mars   # запись basic MARS: $8, смещения переходов
```

Код возврата — код `exit2` (syscall 17), 0 после `exit` (syscall 10) или когда программа выходит за последнюю
инструкцию; исключение без обработчика печатает ошибку и возвращает 5. Файловые сервисы (13–16) работают в папке
программы. `--keys` нажимает клавиши клавиатуры MMIO MARS (следующую — когда программа прочитала предыдущую);
то, что программа вывела на дисплей MMIO, печатается в конце после `[MMIO display]`. У диалогов (syscall
50–59) здесь нет окон: сообщение печатается, вопрос или ввод берёт строку ввода. Строка трассы:

```
00400004  3c011001  lui $at, 0x1001              v0=00000004 a0=00000000 t0=00000000 t1=00000000 sp=7fffeffc
```

`rustemu` без аргументов печатает краткую справку.
