# Горячие клавиши

⌘ — Command, ⌃ — Control, ⇧ — Shift. В браузере те же клавиши. Кроме ⌘N, ⌘W и ⌘T: их браузер странице не
отдаёт, пользуйтесь меню.

## Файлы и сборка

| Клавиши | Действие |
|---|---|
| ⌘N | новый файл (окно шаблонов) |
| ⌘O | открыть |
| ⌘S / ⇧⌘S | сохранить / сохранить как |
| **F9** или ⌘E | собрать и загрузить в эмулятор (*emulate*) |
| ⌘B | собрать в файл (*compile*) |

## Выполнение

| Клавиши | Действие |
|---|---|
| **F5** или ⌘R | Run / Stop |
| **F8** | шаг (Single step) |
| **F10** | шаг через макрос, CALL, INT (Step over) |
| **⇧F11** | выйти из процедуры или макроса (Step out) |
| **⇧F8** или F6 | шаг назад (Step back) |
| **F4** | выполнить до строки с курсором (Run to cursor) |
| ⌘F8 | точка останова на строке |
| F7 | показать текущую инструкцию |
| ⌃F8 | выполнить до инструкции, выделенной в дизассемблере (run until) |
| ⌃⇧F7 | перенести CS:IP на выделенную инструкцию (set CS:IP) |
| F11 | консоль и журнал отладчика |

## Редактор

| Клавиши | Действие |
|---|---|
| F1 или ⌘-клик | статья справочника для слова под курсором |
| ⌘F, ⌘H, ⌃H | поиск и замена |
| ⌘G / F3 | найти следующее |
| ⇧⌘G / ⇧F3 | найти предыдущее |
| ⌘L или ⌃G | перейти к строке |
| ⌘/ | закомментировать / раскомментировать |
| ⌃Q / ⌃W | закомментировать / раскомментировать (Emu8086) |
| ⌃L / ⌃U | нижний / верхний регистр |
| ⌃F2 или ⌘F2 | поставить / снять закладку |
| F2 / ⇧F2 | следующая / предыдущая закладка |

## Отличия от Emu8086

| Действие | Emu8086 | RustEmu8086 |
|---|---|---|
| run / stop | F9 (в эмуляторе) | F5 |
| step over | ⇧F8 | F10 |
| step back | F6 | ⇧F8 или F6 |
| reload | F4 | кнопка **reset** или *file → reload* (F4 — Run to cursor) |
