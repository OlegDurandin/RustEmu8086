# Виртуальные устройства

Как в Emu8086, к эмулятору подключены простые устройства. Программа управляет ими командами `IN` и `OUT`
через порты. Окно устройств — *aux* → *devices* или меню **virtual devices** окна эмулятора; директива
`#start=имя.exe#` в начале программы сразу открывает нужную вкладку.

Устройства работают в реальном времени: робот едет 250 мс на клетку, термометр нагревается со скоростью
часов, а не инструкций.

| Устройство | `#start=` | Порты |
|---|---|---|
| Светофор | `traffic_lights.exe` | 4 (слово) |
| Шаговый двигатель | `stepper_motor.exe` | 7 |
| Робот | `robot.exe` | 9, 10, 11 |
| Термометр и нагреватель | `thermometer.exe` | 125, 127 |
| Принтер | `printer.exe` | 130 |
| LED-дисплей | `led_display.exe` | 199 (слово) |
| Простой ввод-вывод | `simple.exe` | 110 (байт), 112 (слово) |
| VGA state | `vga_state.exe` | 3DAh, 3C8h / 3C9h |

Для каждого устройства, кроме простого ввода-вывода и VGA state, есть пример в **examples**.

## Светофор — порт 4

Слово из 12 бит: четыре светофора (север, восток, юг, запад) по 3 бита. У светофора k бит 3k — красный,
3k+1 — жёлтый, 3k+2 — зелёный.

```asm
#start=traffic_lights.exe#
org 100h
    mov ax, 0000_0010_0100_1001b   ; red on all four lights
    out 4, ax
    ret
```

## LED-дисплей — порт 199

Показывает записанное слово как десятичное число со знаком.

```asm
#start=led_display.exe#
org 100h
    mov ax, 2026
    out 199, ax
    ret
```

## Принтер — порт 130

Каждый записанный байт печатается на «бумаге». Печатать можно и через DOS: INT 21h, функция 05h, или запись в
handle 4.

```asm
    mov al, 'A'
    out 130, al
```

## Термометр и нагреватель — порты 125 и 127

- `in al, 125` — температура в градусах Цельсия (байт со знаком, −65…120).
- `out 127, al` — бит 0 включает (1) или выключает (0) нагреватель.

С нагревателем температура растёт на 1° за 200 мс, без него — приближается к температуре воздуха на 1° в
секунду.

```asm
#start=thermometer.exe#
org 100h
check:
    in al, 125              ; temperature
    cmp al, 60
    jl heat
    mov al, 0               ; warm enough: heater off
    out 127, al
    jmp check
heat:
    mov al, 1               ; heater on
    out 127, al
    jmp check
```

## Шаговый двигатель — порт 7

- `out 7, al` — биты 0..2 включают три обмотки. Двигатель реагирует, только когда значение меняется:
  на полшага или на целый шаг, по часовой стрелке или против — как в Emu8086. Один оборот — 32 полушага.
- `in al, 7` — бит 7 = 1: двигатель готов к следующей команде.

Последовательность полушагов по часовой стрелке: `110b, 100b, 011b, 010b`; против — `011b, 001b, 110b, 010b`.
Полный пример — `stepper_motor.asm` в **examples**.

## Робот — порты 9, 10, 11

Робот ездит по комнате 9×6 клеток со стенами и лампами. Карту можно менять кликом в окне устройства.

**Порт 9 (OUT) — команда**

| Код | Команда |
|---|---|
| 0 | ничего |
| 1 | шаг вперёд |
| 2 | повернуть налево |
| 3 | повернуть направо |
| 4 | осмотреть клетку впереди |
| 5 | включить лампу |
| 6 | выключить лампу |

**Порт 10 (IN) — результат осмотра:** 0 — пусто, 255 — стена, 7 — лампа горит, 8 — лампа выключена.

**Порт 11 (IN) — состояние:** бит 0 — есть новые данные (сбрасывается чтением порта 10), бит 1 — робот занят,
бит 2 — последняя команда не выполнена (например, впереди стена).

Шаг и поворот занимают 250 мс; команда, отправленная, пока робот занят, отклоняется. Поэтому перед командой
ждут, пока бит 1 станет 0:

```asm
#start=robot.exe#
org 100h
    mov al, 1               ; move forward
    out 9, al
wait:
    in al, 11               ; status
    test al, 2              ; bit 1: busy
    jnz wait
    mov al, 4               ; examine the cell in front
    out 9, al
    in al, 10               ; 0 empty, 255 wall, 7/8 lamp on/off
    ret
```

## Простой ввод-вывод — порты 110 и 112

Вкладка *simple I/O* показывает байт порта 110 и слово порта 112. Значения можно менять в окне — программа
прочитает их через `IN`.

## VGA state

- Порт 3DAh: бит обратного хода луча переключается сам, программы, которые ждут его, работают без настроек.
- Порты 3C8h / 3C9h: палитра DAC для режима 13h (индекс, затем три компоненты 0..63).

Вкладка *VGA state* показывает этот бит, видеорежим и палитру.

Любой другой порт ведёт себя как защёлка: `IN` возвращает последнее записанное значение.
