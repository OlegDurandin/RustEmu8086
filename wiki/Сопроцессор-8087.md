# Сопроцессор 8087

RustEmu8086 эмулирует математический сопроцессор **8087** (FPU): к 8086 «подключён» второй процессор, который
считает с вещественными числами. Его инструкции начинаются с `F` и работают в обоих синтаксисах — Emu8086 и NASM.

```asm
; гипотенуза: sqrt(3^2 + 4^2)
org 100h
    finit           ; начать работу с 8087
    fild a          ; ST = 3
    fmul st, st     ; ST = 9
    fild b          ; ST = 4, ST(1) = 9
    fmul st, st     ; ST = 16
    faddp st(1), st ; ST = 25
    fsqrt           ; ST = 5
    fistp r         ; r = 5, стек пуст
    ret
a dw 3
b dw 4
r dw ?
```

## Стек регистров

У 8087 восемь регистров по 80 бит, они образуют **стек**: `ST` (он же `ST(0)`) — вершина, `ST(1)` — под ней и так
далее. `FLD` / `FILD` кладут значение на вершину, `FSTP` / `FISTP` снимают его. Большинство операций работает с
`ST(0)`: `FADD x` — это `ST(0) = ST(0) + x`. Формы с `P` (`FADDP`, `FSUBP`, …) после операции снимают вершину.

В NASM регистры пишутся `st0` … `st7`, в Emu8086 / MASM — `st`, `st(1)` … `st(7)` (обе записи понимаются в обоих
синтаксисах). Слово `st` остаётся обычным именем вне инструкций сопроцессора.

## Числа в памяти

| Директива | Размер | В инструкции |
|---|---|---|
| `dd 1.5` | 32 бита (float) | `dword ptr` / `dword` |
| `dq 1.5` | 64 бита (double) | `qword ptr` / `qword` |
| `dt 1.5` | 80 бит (extended, как внутри 8087) | `tbyte ptr` / `tword` |
| `dw 7`, `dd 7`, `dq 7` | целые 16 / 32 / 64 бита | для `FILD`, `FIST`, `FISTP` |

Дробное число пишется с точкой: `1.5`, `0.25`, `-3.0e-2`. Без точки (`dd 2`) это целое. Переменная `x dq 1.5`
сама задаёт размер: `fld x`; у `[bx]` размер пишут явно (`fld qword ptr [bx]`), без него — 4 байта, как в NASM.
Дизассемблер показывает такие данные числами: `DD 2.0, 0.5`.

## Сравнение и переход

`FCOM`, `FICOM`, `FTST` записывают результат в биты **C3 C2 C0** слова состояния. Перейти по нему — через `SAHF`:

```asm
    fld x
    ficomp n        ; сравнить с n
    fstsw sw        ; слово состояния - в память
    mov ax, sw
    sahf            ; C3 -> ZF, C0 -> CF
    ja bigger       ; x > n (беззнаковые переходы: JA JAE JB JBE JE)
```

`FSTSW AX` — инструкция 80287, она тоже работает.

## Окно FPU

Кнопка **aux** внизу окна эмулятора → **FPU** (или меню окна эмулятора **view → floating point unit**; в режиме
панелей — вкладка рядом с memory) показывает:

- регистры `ST(0)` … `ST(7)` — значение, тег (valid, zero, special, empty) и 80-битный hex;
- указатель вершины `TOP`, биты C3 C2 C1 C0 (подсказка напоминает, как они попадают в ZF / PF / CF через `SAHF`);
- флаги исключений IE DE ZE OE UE PE (поднятые — красным, у каждого подсказка) и управляющее слово: точность,
  округление, маски;
- **raw bytes (as in Emu8086)** — то же, что окно FPU в Emu8086: *control register* — 14 байт окружения
  (как их записывает `FSTENV`: управляющее слово, слово состояния, теги, адреса последней инструкции и операнда) и
  *FPU registers* — восемь регистров по 10 байт, младший байт первым (как их записывает `FSAVE`).

Изменившееся за шаг выделено красным. **Шаг назад** возвращает и состояние сопроцессора.

## Что поддерживается

- Все инструкции 8087: загрузка и запись (`FLD`, `FST`, `FILD`, `FIST`, `FBLD`, `FBSTP`), арифметика (`FADD`,
  `FSUB(R)`, `FMUL`, `FDIV(R)` и формы с `P` и `I`), сравнения, константы (`FLDPI`, `FLD1`, …), `FSQRT`, `FABS`,
  `FCHS`, `FRNDINT`, `FSCALE`, `FXTRACT`, `FPREM`, трансцендентные (`FPTAN`, `FPATAN`, `F2XM1`, `FYL2X`, `FYL2XP1`),
  управление (`FINIT`, `FCLEX`, `FSTSW`, `FSTCW`, `FLDCW`, `FSTENV`, `FLDENV`, `FSAVE`, `FRSTOR`, `FFREE`, …).
- Несколько инструкций 80287 / 80387, которые встречаются в учебниках: `FSTSW AX`, `FSIN`, `FCOS`, `FSINCOS`,
  `FUCOM`, `FUCOMP`, `FUCOMPP`, `FPREM1`.
- Арифметика — точная 80-битная, с режимами округления и точности управляющего слова. Кодирование инструкций и
  дробных данных сверяется с настоящим NASM байт в байт.

## Отличия от настоящего 8087

- Трансцендентные функции (`FPTAN`, `FPATAN`, `F2XM1`, `FYL2X`, `FSIN`…) считаются с двойной точностью (53 бита),
  а не с 64-битной, и принимают любой аргумент (8087 — только ограниченный диапазон).
- Исключения ведут себя как замаскированные: результат — NaN или бесконечность, флаг в слове состояния. Если
  исключение не замаскировано, ставится ещё признак ошибки (ES), но прерывание не вызывается.
- `FWAIT` перед инструкциями ассемблер сам не ставит (как NASM); он есть только в `FINIT`, `FSTSW`, `FSTCW`,
  `FSTENV`, `FSAVE`, `FCLEX`. В эмуляторе сопроцессор работает синхронно, так что ждать его не нужно.

Подробно о каждой инструкции — во встроенном справочнике (**F1**, группа «8087 coprocessor»; есть на русском).
