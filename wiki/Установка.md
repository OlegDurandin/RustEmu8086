# Установка

## Веб-версия — без установки

Откройте **https://olegdurandin.github.io/RustEmu8086/** в Chrome, Safari, Firefox или Edge. Работает на
компьютере, iPad и Android-планшете. Первая загрузка скачивает около 3 МБ, дальше страница открывается из кеша
браузера.

На компьютере открывается интерфейс как в Emu8086, на планшете — [интерфейс для касаний](Интерфейс-планшета).
Программы, настройки и диск C: хранятся в браузере — подробнее на странице [Веб-версия](Веб-версия).

На iPad сайт можно добавить на экран «Домой»: Safari → «Поделиться» → «На экран Домой».

## Приложение для macOS

Нужна macOS 11 или новее, подходит Mac с Apple Silicon и с Intel.

1. Откройте [Releases](https://github.com/OlegDurandin/RustEmu8086/releases) и скачайте
   `RustEmu8086-<версия>-macos.zip`.
2. Распакуйте и перетащите `RustEmu8086.app` в «Программы».

### Первый запуск

Приложение не подписано сертификатом Apple, поэтому macOS предупредит, что не может проверить
разработчика. Откройте его одним из способов:

- **macOS 14 и раньше:** правый клик (или Control-клик) по приложению → **Открыть** → **Открыть**;
- **macOS 15 и новее:** **Системные настройки → Конфиденциальность и безопасность** → внизу
  **Всё равно открыть**;
- **в Терминале:** `xattr -dr com.apple.quarantine /Applications/RustEmu8086.app`.

Это нужно сделать один раз.

### Самая свежая сборка

Сборка из последнего состояния ветки `main` есть в
[Actions](https://github.com/OlegDurandin/RustEmu8086/actions): откройте последний успешный запуск **CI**,
внизу в разделе *Artifacts* — файл *RustEmu8086-macos*. Для скачивания нужно войти в GitHub.

### Командная строка

Внутри приложения есть программа `rustemu` для сборки и запуска без окон:

```sh
/Applications/RustEmu8086.app/Contents/MacOS/rustemu run hello.asm
```

Подробнее — [Командная строка](Командная-строка).

## Windows и Linux

Готовых сборок пока нет — пользуйтесь [веб-версией](Веб-версия). Настольное приложение собирается и
проверяется только на macOS; сборка на других системах не проверялась.
