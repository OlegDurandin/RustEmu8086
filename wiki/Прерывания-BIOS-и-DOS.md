# Прерывания BIOS и DOS

RustEmu8086 эмулирует сервисы BIOS и DOS, которыми пользуются учебные программы. Прерывания «настоящие»:
таблица векторов лежит в 0000:0000, и программа может поставить свой обработчик (INT 21h, функция 25h).

Входные и выходные регистры каждой функции и пример — во встроенном справочнике: наведите мышь на `int 21h`
в редакторе (номер функции берётся из `mov ah, …` выше) или нажмите **F1**.

## INT 10h — видео (функция в AH)

| AH | Функция |
|---|---|
| 00h | установить видеорежим (текст 0–3 и 7, графика 13h) |
| 01h | форма курсора |
| 02h | поставить курсор |
| 03h | позиция и форма курсора |
| 05h | активная страница |
| 06h / 07h | прокрутка окна вверх / вниз |
| 08h | прочитать символ и атрибут под курсором |
| 09h | вывести символ с атрибутом |
| 0Ah | вывести символ, не меняя атрибут |
| 0Ch / 0Dh | поставить / прочитать пиксель |
| 0Eh | телетайп: символ с продвижением курсора |
| 0Fh | текущий видеорежим |
| 10h | палитра, мерцание (AL = 03h), регистры DAC |
| 13h | вывести строку |

Видеопамять — в адресном пространстве: текст — `B800:0000` (2 байта на символ: код и атрибут), режим 13h
(320×200, 256 цветов) — `A000:0000`. Писать в неё можно напрямую.

## INT 16h — клавиатура (AH)

| AH | Функция |
|---|---|
| 00h | ждать клавишу: AL = символ, AH = скан-код |
| 01h | есть ли клавиша (ZF = 1 — нет), не забирая её |
| 02h | состояние Shift, Ctrl, Alt |

## INT 21h — DOS (AH)

**Консоль**

| AH | Функция |
|---|---|
| 01h | прочитать символ с эхом |
| 02h | вывести символ из DL |
| 05h | символ на принтер |
| 06h | прямой ввод-вывод |
| 07h / 08h | прочитать символ без эха |
| 09h | вывести строку DS:DX до `$` |
| 0Ah | прочитать строку в буфер |
| 0Bh | есть ли символ |
| 0Ch | очистить буфер клавиатуры и вызвать функцию из AL |

**Файлы и папки**

| AH | Функция |
|---|---|
| 3Ch / 5Bh | создать файл / создать, только если его нет |
| 3Dh / 3Eh | открыть / закрыть файл |
| 3Fh / 40h | прочитать / записать (handle 0–2 — клавиатура и экран, 4 — принтер) |
| 41h | удалить файл |
| 42h | переместить указатель |
| 43h | атрибуты файла |
| 56h | переименовать |
| 4Eh / 4Fh | найти первый / следующий файл |
| 39h / 3Ah / 3Bh | создать / удалить / сменить папку |
| 47h | текущая папка |
| 19h | текущий диск |

**Прочее**

| AH | Функция |
|---|---|
| 25h / 35h | установить / получить вектор прерывания |
| 2Ah / 2Ch | дата / время (по часам компьютера) |
| 30h | версия DOS |
| 48h | выделить память |
| 4Ch | завершить программу, AL — код возврата |

В упрощённом виде есть и 0Dh, 0Eh, 1Ah / 2Fh (DTA), 2Bh / 2Dh, 31h, 33h, 36h, 44h, 49h, 4Ah, 4Dh, 50h.
Запуска других программ (4Bh) нет.

### Где лежат файлы

Файловые функции работают в «песочнице» (диск C:):

- **в приложении для Mac** — папка `~/Documents/RustEmu8086/vdrive/C`, как `vdrive\C` в Emu8086. Открыть её —
  *Emulator → Virtual drive → show drive C: folder*. В окне **options** (*drive C:*) можно выбрать папку
  программы: тогда программа видит файлы рядом со своим исходником, но может их изменить и удалить. Выйти за
  пределы диска нельзя, в том числе через символьные ссылки;
- **в браузере** — диск в памяти браузера, до 2 МБ, окно **drive C:** — см. [Веб-версия](Веб-версия).

## Другие прерывания

| INT | Что делает |
|---|---|
| 20h | завершить программу |
| 11h | список оборудования (число дисководов) |
| 12h | объём памяти |
| 13h | дискеты: 00h сброс, 02h чтение, 03h запись секторов, 08h параметры; DL = 0..3 — FLOPPY_0…FLOPPY_3 |
| 15h | 86h — пауза на CX:DX микросекунд (реальное время) |
| 19h | перезагрузка — завершает программу |
| 1Ah | 00h счётчик тиков, 02h время, 04h дата (BCD) |
| 33h | мышь: 00h сброс, 01h / 02h показать / спрятать курсор, 03h позиция и кнопки, 04h поставить курсор |

**Таймер.** Счётчик тиков BIOS (0040:006C) идёт по часам компьютера, 18,2 раза в секунду. Аппаратное
прерывание IRQ0 (INT 08h → INT 1Ch) включается галочкой **timer IRQ** в окне эмулятора, в командной строке —
`--timer-irq`.

**Дискеты.** *virtual drive* в окне эмулятора: до четырёх дискет 1,44 МБ, загрузка и сохранение образов
(подходят `FLOPPY_n` из Emu8086), запись загрузочного сектора, загрузка с дискеты. Дискеты хранятся в памяти —
чтобы сохранить, используйте **save floppy image**.
